# Diabetes Care | ডায়াবেটিস কেয়ার

ডায়াবেটিস রোগীদের জন্য free platform — সুগার ট্র্যাকার, রিপোর্ট সংরক্ষণ, ডাক্তার অ্যাপয়েন্টমেন্ট, কাছের হাসপাতাল।

**Stack:** Next.js 16 · Tailwind v4 · Supabase (Postgres + Auth + Storage) · Vercel

👉 **Setup instructions: [SETUP.md](SETUP.md)**

```bash
cp .env.example .env.local   # Supabase keys বসান
npm install
npm run dev
```
